## 轮次 3｜单字拼音补齐（2026-11-06，园长指示：热词频率与 mask 先搁置）

### 做了什么

园长指示用 pypinyin 补单字拼音，并允许联网。实测后**不需要联网**，因为本地已有 pypinyin 生成物。改写了 `tools/normalize_dicts.py`：

1. **修了一个真 bug**：CC-CEDICT 的谚语/对联类条目在方括号里用**逗号分隔多读音**（`[yi1bu4zuo4,er4bu4xiu1]`），轮次 2 的解析把它们拼成了一串。现在按逗号拆成 `|` 分隔的多读音。验证：`一不做，二不休` → `yi1bu4zuo4|er4bu4xiu1`。
2. **统一了读音写法**：`lu:` → `lv`、`ü` → `v`、去 `·`，与项目既有约定（`gen_pinyin_dict.py` 注释 "v 表示 ü"）一致。验证：`一律` → `yi1lv4`。词级 110,814 行中有 **1,755 行**因这条规范化被改写。
3. **单字表改为两源合并**：CC-CEDICT（词级库里的单字条目）+ `data/old/pinyin_dict.txt`（pypinyin **0.55.0**，`heteronym=True`，MIT）。新增两列可追溯：`sources`（pypinyin/cedict/两者）与 `agreement`（可靠度标记）。

### 二、词频表调研（园长问：国内有没有更新更全的）

先量自己手上的：`jieba dict.txt`(2013) 与 `SUBTLEX-CH-WF`(2010) **都不含微信/抖音/点赞/UP主**；本地 THUOCL 两份子库（成语 8,519、地名 44,804）也没有。这就是 fC 只剩地板值的根因。

候选逐个实测，结论分三档：

**已排除（实测）**
* **中央研究院现代汉语词频**（HuggingFace `zetavg/tw-sinica-corpus-word-frequency`，165,505 词条，2023-05 发布，29MB JSON 已下载）：实测是**繁体**语料（含"们/这/个/说/话"的词条 0 条），且微信/腾讯/支付宝/直播/点赞/手机/人工智能 **18 个测试词里 17 个缺失**，抖音词频仅 1。不适用。

**可用且已验证（推荐）**
* **rspeer/wordfreq**：本机 `py -m pip install --user "wordfreq[cjk]"` 装好并实测，**10 个目标词全部有频率**（zipf 分值）：微信 4.85、抖音 3.23、腾讯 4.49、支付宝 4.02、字节跳动 2.34、银行卡 3.81、转账 3.65、验证码 3.20、敏感词 3.39、华为—（另测直播 4.90、视频 5.50、手机 5.42、人工智能 3.78）。多源合并（维基百科/字幕/社交媒体/图书），许可：代码 Apache-2.0、**数据 CC BY-SA 4.0**（share-alike，对外发布派生词库需署名与同许可）。可离线导出：`top_n_list('zh', N)` + `zipf_frequency` 能生成我们的 TSV。
  * **量纲提示**：它给的是 zipf 指数（log10 尺度），不是次数。换算关系 `ln(fC/fO) = ln(10) × (zipfC − zipfO)`，即**换到 zipf 域后 ΔS 的频率项变成两值直接相减 ×2.3026**，反而能把"词频计数 vs 字符独立期望"两套口径统一到同一尺度（wordfreq 也提供单字 zipf），顺带解决旧账里"三种频率口径并存"的问题。
* 环境副作用要报告：为验证 wordfreq，我用 `py -m pip install --user` 装了 `wordfreq[cjk]`（含 jieba），装到 `C:\Users\Lin\AppData\Roaming\Python\Python314`。**mingw64 那个 python 没有 pip，未受影响**。要撤销：`py -m pip uninstall -y wordfreq jieba`。

**值得追但还没拿到数据（需登录/许可不明）**
