# Claude近似公式：待批准的实验方案

2026-11-07。**仅方案，尚未实现或校准，不替换生产评分。**第一阶段E022已让旧判决流程使用新通用词频并完成工程回归；开卷误改仍明显，不能据此证明算法有效。

## 要验证的命题

在同一候选池、窗口、AC锁定、读音约束和KEEP规则下，比较：①零操作；②E022频率差公式；③Claude近似模型。研究目标是判断模型是否在保留正确修复的同时降低坏编辑，而不是让概率形式看起来更完整。

原提案为：

`Odds(h:KEEP) ≈ εw × Pdoc(h) / Zh × LRctx`

这还不能直接称为后验赔率。若观测原文为x，真正的后验赔率涉及 `P(x|h)/P(x|KEEP)` 与先验赔率；仅有“发生错误的概率”并没有描述“恰好错成x”的可能性。还需说明KEEP的先验与正确识别概率放在哪里。`Zh`按目标h归一化与按观测x归一化不是同一件事。以下均是要检验的估计方案，不声称已完成推导。

## 拟采用的第一版实现

所有运算在对数空间中完成，KEEP为参考分数0；缺失任何必要证据先保留原文并记原因，不靠极小数制造巨大优势。实现放入独立实验目录，复制冻结生产候选选择流程，完整重跑；不从既有最终编辑中事后筛选。

| 项 | 第一版可检查的估计 | 要防止的问题 |
|---|---|---|
| εw：识别出错概率 | 以词窗是否有真实识别错误作标签，仅用可靠对齐的Whisper token p、窗长、段边界位置拟合一个小型校准器；不把p直接当字级阈值。无p时另设缺失分支或保留原文。按视频/UP划分拟合与验证。 | token与汉字不一一对应；高p错误仍存在；把某次识别出错与“应改成这个h”混为一谈。先检查可靠性曲线及实际误判数量，AUC只作补充。 |
| Pdoc(h)：视频词先验 | 通用 `10^(Zipf-9)` 为基础；标题/简介与原始正文分别计数，再用训练数据选择的收缩权重融合。正文证据不从纠错后输出回灌；对当前被判窗口采用留出该窗口的计数。 | 缺失通用词频、错误ASR重复放大、标题与正文重复证据、把真值领域列当当前视频信息。第一版禁用当前正式表的ours列。 |
| Zh：近音竞争概率总量 | 在冻结的普通词典与有可靠读音的词条中，按长度建立音近邻集合；每个词只计一次，累加通用概率。检索口径预先固定，包含KEEP等合理竞争项，不用前64个候选代替完整近邻。 | 读音缺失、词表截断、多音词重复计数；使用Pdoc还是通用概率会改变归一化含义，需单独对照。wordfreq多词估值不一定构成严格归一的词分布，先称“近邻质量代理”。 |
| LRctx：上下文似然比 | 第一轮固定为1，先看其余项是否有用。第二轮才加入独立训练的字符N-gram上下文比值，固定左右上下文长度，不跨句；用条件概率相对无上下文先验的提升，比较h与KEEP。 | 直接用“候选在上下文中概率高”会再次计入词频。避免与Pdoc重复计算标题/正文证据；未见N-gram不能直接判零。 |

第一轮只实现两种对照：Claude骨架（LRctx=1）和加入上下文项的版本。若εw无法校准、近邻覆盖过低或骨架比零操作更差，不继续叠加特征；先定位哪项估计失效。

还需一个必要的检查：给近音混淆分级估计 `P(x|h,error)` 的简单分布，观察原提案仅靠εw/Zh是否能近似它。若不能，报告模型假设失败，再申请修订公式；不能偷偷把新混淆模型塞进原公式并说验证成功。

## 平滑和阈值如何定

- 对统计错误率可比较Beta收缩估计与常数错误率；收缩强度只在开发集选择。不能把Whisper的1−p直接认作校准后的εw。
- 对未收录词频、读音或零近邻质量，第一版直接保留原文，并报告因此漏掉多少可修错误。若探索频率下限或背景质量补偿，作为明确的开发集消融，不能借新测试真值调下限。
- 对N-gram只采用一种公开写明的加性/回退平滑，先在开发集固定；不为每条错例单独设规则。
- 修改门槛和候选竞争间隔在开发集确定后冻结。不能宣称概率模型不再需要阈值，也不把原μ原封不动冒称新模型的校准门槛。

## 数据隔离与执行顺序

1. 当前7篇全部是**开卷开发/回归数据**，候选与领域统计已使用它们；哪怕再按视频拆分，也不能自动变成干净测试集。可用于排错、初步校准及构造反例，所有数字明确标记开发结果。
2. 冻结代码、词库、分词、近邻范围、估计方法、参数和数据SHA。开发语料中重复/同源视频一组处理，报告分组结果。
3. 最终验证必须等到**未参与候选抽取、领域计数、拟合与调参的新人工真值**。当前没有这样的数据，因此现在不能完成第二阶段有效性结论；不要求马上追加大规模标注。后续正常产生的小批新稿可以先作验证，但样本不足时只报告计数与不确定性。
4. 新视频标题、简介、原始ASR可以给各方案相同地使用；新真值只在最终计分时打开，禁止据此补候选。若关键词根本不在冻结候选池，单列覆盖不足，不临时加词再重跑当盲测。
5. 三方案使用完全相同测试输入、discard、数字排除和已有对齐规则；含候选竞争完整重跑。统计正确原文被改坏、改对、错到错、漏改、保留原有正确修复的位置及总编辑距离。算不了的片段仍列未知，不当正确。

## 待批准的验收条件与停止条件

建议沿用此前研究的比较要求：相对E022，在同一新验证集上保留至少95%的原有改对字符，坏编辑（误改＋错到错）减少至少30%；总编辑距离不得差于零操作。按视频/来源分别报告，不让某一长稿掩盖其他域恶化。门槛是**待批准的实验要求**，不是本阶段擅自改变工程验收标准。

另做相同改对保留率、相同误改预算下的比较；操作点必须在开发集冻结，测试集曲线只作描述。少量正确编辑导致比例不稳时，直接给“保留x/y、误改a→b”，不作强泛化结论。

可能的负面结果：εw只识别幻觉段，对候选选择无帮助；Zh惩罚常见读音后丢大量真修复；Pdoc把重复ASR错误当领域词；上下文项把历史专名改成常用词；最终仅靠少改获得零误改、同时失去几乎全部修复。任何一种都如实报告，并与零操作比较，不再扩大特征列表掩盖失败。
