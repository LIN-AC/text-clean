# 新增人工真值上的冻结策略验证（E19）

日期：2026-11-04。HEAD：`14aad4667c09587cd47eb64ea33b670da6a61668`，含既有未提交 E8 工作树；并非干净 v1.2.2。生产代码、评分公式、正式词典和人工真值均未修改。

## 结论

新数据改变了研究重点：**目前更需要限制候选词表带来的错误替换，而不是继续微调拼音门槛。** 同音或来源可信只能说明一个词存在，不能说明它适合当前句子。

1. 研究用 CSC＋成语大词表，距离2→1使新六篇正确原文误改从496降到268，但仍远超正确修复；完全同音也有147个误改。所有大词表组都增加了相对真值的总编辑距离。
2. 默认小词表＋成语表现明显较好。新六篇距离1为7 TP / 1 FP / 0错到错，修好8个字；代价是对400个可唯一对齐的替换错误只召回2%。不能把它称为通用ASR纠错方案。
3. 声调变化有实测价值：成语配置strict→tone，TP从5增到7，FP仍1。此前鼻音窄例外在新六篇增益为0；仅在旧历史稿复现已知的“兵令城下→兵临城下”。不应把两个旧样例的收益升级成通用策略。

## 固定条件与评价口径

复用E16已经定义的策略及候选数据：大表=`log/thuocl/ctc_idiom_d2.lexicon`；小表=`data/lexicon.txt`；小表＋成语=`log/thuocl/default_idiom.lexicon`。不从新真值提词，不调λ、μ或支持阈值。λ=.65、μ=.70，默认字符频率基线开启，首音节门、窗口、64候选上限及冲突选择保持原样。未额外提供标题/简介上下文。

每组**完整重跑候选检索、窗口生成、评分及最终选择**，不是从基线输出删编辑。实验版base与未加实验门的同源二进制在七篇上stdout逐字一致。E16保护快照与当前所有src/include哈希相同，baseline副本与当前生产`text_cleaner.cpp`字节一致。

采用所有最优Levenshtein路径的前后向对齐，仅在某个源字的目标位置唯一且不能删除时赋真值；歧义、删除、数字相关修改不猜标签。新六篇排除72个数字相关源字符、25个歧义/删除字符。另计算整cue归一化编辑距离，覆盖插入/删除及数值错误；它是辅助误差量，不是字级召回分母。

- TP：本次编辑实际改变的字全部改对。
- FP：本次改变的字原本全部正确。窗口中未改动的字仍可能有其他错误；不是要求整句原本正确。
- 错到错：其余已知编辑，包括部分改对、部分仍错的混合编辑。
- 排除：至少一个改动位置不能可靠归因。大表多数配置3处，train2为5处，不能当成正确。
- 字符级另统计每个已知改动位置，包含混合/排除窗口中仍可可靠判断的位置。因此窗口TP数和改对字符数不能互换。

## 下一方向与暂不做的工作

下一项最值得做的实验是：**在同一大候选词表、固定拼音条件下，仅按候选长度（2、3、4字）分桶开关准入，完整重跑选择，分离长度和来源标签的贡献。**保持词频、来源和目标词读音不变，不同时叠加新的边界规则。先用旧历史稿确定唯一对照，不再按新六篇逐例加规则；新六篇已经看过，应称跨视频复核，不再冒称未触碰的盲测集。无需追加大规模标注。

验收：相对对应同词表基线，原有改对字符保留≥95%，FP＋错到错减少≥30%；每个来源组输出编辑距离不得增加，并单列零收益域。原TP身份保留与净TP同时报告。可能的负面结果是只靠禁止短词消除误改，同时把术语/专名的纠错能力清空，或成语收益完全来自长度而非来源。出现这些情况就否决通用准入，不用调低阈值补回。

暂不：上线鼻音例外、完全同音优先、全局source/doc_support硬门；不动态化λ/μ，不把Whisper p加到字级门槛或ΔS，不机械加PMI，不扩展全量AC，不按本批例子加入黑名单。有限成语配置值得继续研究，但样本少、召回低且仍有已知坏编辑，暂不改生产默认。
