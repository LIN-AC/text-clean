# THUOCL 候选来源实验（2026-11-04，Astra）

结论：成语词库作为定向补充有实测收益；“只有外部词库收录才允许纠错”的通用硬门失败。暂未把词库或参数接入生产默认配置。

## 条件与来源

- 项目 HEAD：`14aad4667c09587cd47eb64ea33b670da6a61668`，工作树已有 E8 补丁；使用既有 `build-v123/text_clean.exe`，不声称旧二进制与当前源码逐字对应。源码、人工标注、默认字典均未修改，实验前后哈希一致。
- 上游：https://github.com/thunlp/THUOCL ，固定 commit `a30ce79d895d01ab5132a5c74c29703ff7efb4cc`。本地 `data/THUOCL_chengyu.txt` 与上游规范化词/数值逐行一致；历史名人表、README、MIT LICENSE 下载至 `log/thuocl/`，没有直接安装进默认词库。
- 上游数值是 Document Frequency，即包含词条的文档数量；成语及历史名人来自新浪新闻语料。它不是本项目静态词频的同量纲计数，也不是在当前视频中的正确性证据。只用于词表成员/DF≥2准入实验，不加到 ΔS 或静态词频。
- 8,519 成语中，7,874 条符合纯汉字、2–4字、拼音字典完整的现有候选限制；其中4,904条静态词频非零。13,437条历史名人符合相同限制。没有利用ASR真值挑词或生成别名。
- 沿用自动拼音 `-`（首读音派生），没有伪称THUOCL提供词级读音。仅1,748个可用成语的所有字符都具有唯一无声调读音；此限制另外做消融。
- λ=.65、μ=.7、空视频上下文、原segment间LF、现有AC/保护词表/静态频率不变；仅通过临时lexicon及现有 `--max-distance` 运行完整程序。没有修改算法或评分。

## 评测范围

ASR使用 E14 已确认的1,121个片段、2,046个字符，通过原始文件哈希和源切片校验；只有所有**改动位置**都有真值的编辑才评分。TP=改动字全部正确，FP=已正确原字被改坏，wrong=错改成另一个错；TP不等于整个成语/句子完成独立核验。未知编辑单列，不算正确。

异域拼写测试固定为 SIGHAN15 test 全部1,100条、cscd-ns/test前2,000条等长句、lemon/nov前2,000条等长句，总5,100句、2,831个已标错误字符。全部候选来源独立于这些测试真值，但这些基准此前已被研究，不能称全新盲测。正确文本为 `temp_txt` 三文件：人民日报、国家监委公布李文亮事件调查结果、九曲安澜万象新。

## 反例、代价与验收

- 正向例：`囤积居齐→囤积居奇`、`穷兵独武→穷兵黩武`、`伟大不掉→尾大不掉`、`历经图治→励精图治`。
- 正确原文反例：`争权独立→争权夺利`；正确新闻文本还有 `意见制度→一箭之地`。二者在距离1对照消失。来源可靠不等于语境适用。
- 错到错：`立国立民→为国为民`，人工已确认的改动字应为“利”。诊断距离0；字典含 `立 li4,wei4`，输入侧稀有异读仍能制造假同音。即使只保留目标唯一无声调读音，也未消除此例；本轮未据单例添加规则。
- 大词表候选竞争会压掉成语修复：距离2时默认＋成语TP24，而CSC＋成语TP19。完整重跑是必要的，不能把独立词表命中简单相加。
- 硬筛方案未达到原定验收：虽然误改大幅减少，ASR基线17个改对字符只保留1个；异域改对字符214→15，远低于95%保留要求。新增成语TP不能掩盖原有修复的丢失。
- 降距并加成语也不能冒充“保留原基线”：相对距2基线，距1＋成语只保留ASR原17个改对字符中的11个。它对距1对照是净收益，但不满足距2基线的保留要求。
- 历史名人补充增加本片TP，同时正确文本误改388→404（相对成语扩展组）；本片题材适配不能充当全局启用依据。
- 成语中37.7%可用项静态词频为0；现有评分与多音字处理限制了收益。没有把DF直接当词频“补救”，也没有全量修正候选读音。

## 方向

支持继续验证“成语作为有限领域候选补充”，不支持用外部词库成员资格替代通用候选判决。距离1下的增量最明确，但应保持为实验配置；默认小表＋成语/1仍有一个已确认错到错案例及三个未知编辑，不能宣布安全上线。历史人名不全量启用；动态λ/μ、p评分、全量AC硬锁均未实施。

本轮只验证准确性，运行日志中的单次总时长包含加载和诊断输出，不当作吞吐或启动性能结论。

## 复现

在项目根目录、MinGW运行库可用的环境下：

```text
python log/thuocl/experiment.py
python log/thuocl/experiment.py --followup
```

首轮9组预先写入 `protocol.json`；看到成语/距离结果后，追加默认表与默认＋成语/1两组，写入 `followup_protocol.json`，明确属于后续确认，非全程盲测。

上游版本/URL/哈希：`log/thuocl/upstream.json`；输入与二进制哈希：`hashes.json`；逐组结果：`results.json`；ASR逐编辑：`asr_edits.json`；所有临时词表、输入、stdout、stderr与可复现脚本均在同目录。人工标注及生产配置未动。
