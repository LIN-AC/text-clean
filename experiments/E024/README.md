## 二、第一轮 K 扫错了区间（如实记录）

E023 我建议扫 `K∈{1,1.5,2,3}`，跑出来**四档结果完全相同**（见 `results/round1_saturated_K.txt`）。原因是换算漏项：旧式缺证据额度 `ln(1+fC)≈1.4` 是**自然对数**，换成 Zipf 档要除以 `ln10`，即 `Δzipf≈0.61`。所以有效区间在 0.1～1.0，我第一轮选的值全部落在饱和区。第二轮改用 `K∈{0.15,0.3,0.45,0.6,0.9}`。

由此得到一条可直接使用的解析关系（本轮实测逐点验证）：

```
只有当 K > (μ + λ·d) / ln10 时，缺证据的原文才可能被放行
d=0 → K > 0.304     d=1 → K > 0.586     d=2 → K > 0.868
```

所以 K=0.15/0.3 的数字与基线 veto **完全一致**（不是巧合，是数学必然），K=0.45 只放 d=0，K=0.6 放 d≤1，K=0.9 连 d=2 也放。

## 四、读法与结论

1. **M1 有效**：只把"原文缺证据→弃权"换成字频估计，改对字 20→230、总距离 2090→1934，验证了 E023 的归因。代价是误改字 86→140（无上限时字频估计可以给到 3～5 档的便宜）。
2. **封顶是必要的**：`M1+M2 K=0.6` 把误改字从 140 压回 **93**（低于旧次数口径的 97），改对字仍 **210**（高于旧口径 194），总距离 **1907 = 本批最好值**（旧口径 1927、不纠错 2024）。
3. **M2 单独不推荐**：FixedCap 完全丢掉原文实际证据，只按常数给额度，本质是 E023 消融 B 的受限版；同一距离水平下它的误改高于 M1+M2（K=0.6：102 vs 93）。
4. **K 不是新调参旋钮**：它的作用是"最多允许多少额度"，且由 `K>(μ+λd)/ln10` 直接决定放行哪一档距离。想只放同音（d=0）→ K≈0.35~0.45；想放到 d=1 → K≈0.6；不建议 ≥0.9（等于放开 d=2）。
5. **K 治不了方向相反那一族**：`杨炎→扬言`（zipfC 3.64 vs 真值"杨炎"）、`税几→税基`（原文 zipf 2.77 仍低于候选，过线）——通用语料里错词形态更常见，属候选侧/上下文侧问题（E023 已量：109 个双侧有证据配对里 82 个方向反）。
6. **需要园长审定的原则问题**：E022 README 明确写过"不偷用领域次数，**不用旧的字符次数估算填 Zipf 缺口**"。M1 恰恰是把字符独立估计请回来（换了 Zipf 尺度并加封顶）。技术上我按 E023 的建议实现了，但这是对已声明设计原则的变更，**不该由我默认掉**。

## 八、M3（`--target-fallback`）：七篇上零改变

实现：目标词缺词级 Zipf 时取 `Σzipf(字) − 9×(n−1)`，仍受 K 封顶；默认关闭。矩阵扩到 15 臂（`experiments/E024/scripts/arms.py`，`arms.json` SHA ec7aafffd40eacc2）。

非失效证明：`test_missing_evidence` 19 项断言通过，第 8 项显示 2 字目标的兜底会触发（Δzipf=0.5 → 放行），第 9 项显示 4 字成语型必被拒。8 个目标词兜底值：卖官鬻爵 −11.26、士绅富户 −10.81、纳粟二石 −9.66、轻徭薄赋 −11.97、以建居为簿 −9.91、在祥符决口 −11.90、堵口赈济修复 −19.69、用下划线标注 −13.87，而这类词组真实 zipf 约 1～3。
