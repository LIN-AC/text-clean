# E026｜真值漏斗：正确候选到底在哪一关丢失（2026-11-08，只诊断，不改生产码）

分支 `exp/m1-m2-missing-evidence`。本轮唯一的生产码改动是**按园长批准删除 M3**（`--target-fallback` 及其兜底分支），删除后默认输出与 E024 二进制 7/7 逐字节相同、Z2 臂复现 147/100/27/1977、ctest 24/24。冻结输入、脚本 SHA、臂配置断言见 `results/manifest.json`。

## 一、配置统一（防止混用不同评分臂）

固定：同一个二进制、同一份 `data/` 词库与候选池与 AC、同一份 `asr/` 真值。三臂为

| 臂 | 参数 | 本轮实测 | 必须等于 E025 记录 |
|---|---|---|---|
| Z1 | zipf 默认 veto | 64 改对字 / 87 误改字 / 2047 | 是 |
| **Z2（控制臂）** | `--missing-evidence char --missing-cap 0.6` | 147 / 100 / 1977 | 是 |
| C2 | `--word-freq data/old/word_freq.txt --char-freq data/old/dict.txt` | 196 / 97 / 1925 | 是 |

三臂数字逐条对不上就中止（`inventory.py` 内置 assert），所以后面的漏斗不存在"拿 A 臂的通过数配 B 臂的失败数"。

## 二、真值实例

错误实例 = 一行内连续的不一致位置（唯一最优对齐才计入，歧义位置整条排除；口径与 E022–E025 完全相同）。
规模：**1,474 个实例 / 1,921 个字**（字数即历史上一直报的"原替换错字 1,921"）。

判因器（`replica.py`）复刻候选读音、逐音节距离、近音门、证据存在性与分数，并在二进制真实产出的拼音编辑上逐条校准：**Z1 37/37、Z2 89/89 距离与分数完全一致**，因此才允许用于"没发生"的实例。

|---|---:|---:|---:|---|

Z1 对照（同一判因，只换臂）：S0 36、S1a 1,071、S1b 61、S2 58、S3 24、S4 2、S5 221、S7 1。
**M1+M2 把 48 个实例从"没改"变成"改对"，其中只有 16 个是从 S4/S5 救回的（32 字），其余是更长窗口顺带命中的单字。**

关于"S6 已生成正确修改却在输出阶段丢失"：`inventory.py` 对每一臂断言"二进制打印出的编辑一律已落到 stdout"，全部通过，因此不存在打印后丢失；竞争阶段的丢失只表现为"未打印"，已由 S5/S7 覆盖。

**账目对得上**：Z2 的 147 个改对字 = 84 个整段改对实例的 131 字 + 12 个"段内部分改对"实例的 16 字（改对了段里某些字，但整段没到位，这 12 个仍按首次失败关计入下表）。实例口径与字口径之间不再有解释不上的差额。

## 四、S5：正确候选进了评分却被拒绝（206 实例 / 435 字，占全部错字 22.6%）

* **206 条全部是"原文本身有词级证据"**，即通用域词频里这个错写法并不罕见 —— 不是缺证据，是方向不对。
* 分数分布：≤−1 有 163 条，(−1,−0.5] 16 条，(−0.5,−0.1] 25 条，(−0.1,0] 只有 2 条。**绝大多数不是差一点点，而是差得远**，调 μ 救不动（本轮也未调）。
* 拼音距离分布：d=0 112 条、d=1 48 条、d=2 46 条。
* 典型（原文 / 真值 / 候选 / 复算分 / 拒绝原因）：
  * `书里 → 梳理` d=0，zipf 3.31 vs 3.60，score −0.032 —— 目标更常见但幅度不够准入门。
  * `断手 → 段首`（同一片语出现 6 次）d=0，zipf 3.48 vs 3.60，score −0.424。
  * `纳典 → 那点` d=0，zipf 2.93 vs 3.21，score −0.055。
  * `轻描 → 青苗` d=0，score −0.101。

## 五、S1a：最大的一块是"单字错误"，与公式和保护规则无关（1,080 实例，含已改对 40）

| 性质 | 实例 |
|---|---:|
| 严格同音（同音节同声调） | 670 |
| 同基音不同调 | 218 |
| 基音不同（近音） | 182 |
| 读音表缺字 | 10 |
| 能被"包含该字的更长启用目标词"顺带命中 | 99（其中 2 字窗 90） |
| 单字频率方向：ASR 字比真值字更常见 | **661** |
| 单字频率方向：真值字更常见 | 407 |

结论两条：① 现结构（最短窗口 2 字 + 池内最短目标 2 字）对 73% 的真实错误天然不可达，能顺带救的只有 99/1,080；② 即使将来允许单字窗口，61% 的单字错例在通用域字频上"错字更常见"，单字纠错的精确率预期会很差。这是词库与算法定位问题，不是评分参数问题。

## 六、对照旧次数臂：C2 改对而 Z2 没改对的 62 个实例死在哪

S5 35 个 / S1a 24 个 / S1b 2 个 / S4 1 个。
即新版丢的正确修复，一半以上是同一件事：**旧表查不到这个错串**（fO=0 → ln(1+fC) 大礼），而新表查得到且和真值同档，于是被方向否决。真正"两表方向相反"的新增损失只有约 35 条 S5，另有 24 条是单字（旧臂靠更长窗口或 AC 顺带改对，新臂在池外没赶上）。

## 七、疑似真值错误上报（本轮一条都不改）

启发式（真值片段在所有词频表查无、而 ASR 片段是常见词）挑出 2 条，人工复核结果：

* `红五星财政的本质 → 洪武型财政的本质`（BV1uUak6pEdK，行 3541）：**不是真值错误**，"洪武型财政"是真实术语，属 ASR 同音误识。
* `咬伯父 → 徭薄赋`（同篇 6135）：**判因假象**，它是 `清姚伯父 → 轻徭薄赋` 的跨窗切分片段，不是独立错误。

所以本轮**没有发现新的疑似真值错误**，也说明该启发式在这批数据上的命中率为 0/2，不建议直接用它当真值质检。

## 八、一句话结论

真实错误的丢失顺序是：**单字错误结构不可达（70.6%）> 进入评分但方向被否（14.0%）> 索引取不到（3.9%）> 多字池外（4.0%）> 拼音硬门（1.6%）> 缺证据弃权与竞争（0.2%）**。评分公式和保护规则都不在主要损失里。

## 九、已知限制与复现

* 判因器只复刻 Zipf 两臂；窗口边界许可与贪心分词（D8 那族）未单独建模——若某实例既没被枚举成窗口、又恰好分数≤0，会被记进 S5 而不是 S2。S5 里"≤−1 的 163 条"可能包含这种混合情况，需要探针级插桩才能拆开，而本轮承诺不改生产码。
* S1a 的判定依据是候选池实测无 1 字目标词；没有实测"允许单字窗口"的收益（那属于改动流水线，需园长批准）。
* 全部开卷；数字为同源结果，不代表泛化。
