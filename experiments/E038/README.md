## 1. 实现与兼容性

修改`tools/rag_clean.py`、`tools/prepare_rag_package.py`、`tests/test_rag_clean.py`，更新`docs/RAG_DATA_CONTRACT.md`的E038接口说明；本目录保存冻结代码、对照脚本和结果。

- **跨换行修复**：逐字获取真实连续汉字段，移除`$`可匹配末尾换行之前的行为。运行中逐窗口使用独立`\Z`锚定检查，防止旧问题回归。
- **来源与位置**：新版`tc-rag-2`实际保存原料doc_id/seg_id、Unicode字符offset、左右边界、来源组；检索日志保留使用的块、位置和边界。来源组属于documents，通过引用取得，不在每个块重复存字符串。
- **句界处理**：明确句末标点才提供BOS/EOS（句首/句末标记）；现代句库文档头尾可视为边界，历史文档头尾不据此发标记。逗读、换行、数字、引号和不明符号两侧不强行拼接，也不伪装成句末。ASR内部换行不提供句界；完整输入最外层头尾视作文档边界。
- **通用模型同步修正**：现代原料按同样边界训练字符4-gram。未知左边界使用可用短历史降阶，不填造BOS；领域计数只记录具备完整3字历史的转移。未知右边界不发EOS。
- **载荷限制**：每块正文最多256字、不重叠，另带同一连续汉字段之前最多3字；每窗口最多50块、实际计数载荷最多8192字（正文加前文）。预算截断处不发EOS。分块前后有效内部转移一致，由机制测试验证。
- **旧入口兼容**：C++及默认V1没有修改。旧包仍可加载，`--legacy-boundaries`仅用于重建旧边界口径的研究对照；新原料默认建v2包。未校准包继续默认KEEP，研究须显式`--research`。

初值完全不变：same/tone/near均a=0、β=1；κ=10、ρ=1、α=.01、H=30、检索上限50。两份新包的parameters.json与E037逐值一致。256/8192是固定工程载荷限制，未用真值选择最优值；G/D/S/KEEP的公式未改。

失败目录仅作未完成产物保留，**不是可用包**。本轮完成的包是`build/e038_train_v2`、`build/e038_full_v2`；旧边界控制包为`build/e038_legacy_train`。全部新建目录，未覆盖E035/E037包。
